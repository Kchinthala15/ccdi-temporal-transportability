# Temporal transportability of pediatric cancer risk factors and risk tools

Analysis code for SmartDaaS LLC's Milestone 1 entry to the NCI Childhood, Adolescent and Young Adult Cancer Data Innovation Challenge (Phase I, Track 2): *Do Neuroblastoma Risk Factors and Risk Tools Hold Across Treatment Eras? Temporal Transportability of Prognostic Biology Using CCDI Resources.*

The model results, hazard ratios, interaction tests, calibration estimates and Figure 1 in the Milestone 1 submission can be reproduced from this repository using open-access data from the NCI Genomic Data Commons (GDC).

## What it does

- **Neuroblastoma (TARGET-NBL).** Trains a Cox model on established factors (age at diagnosis ≥18 months, INSS stage, *MYCN* amplification, ploidy) in children diagnosed through 2008 and tests it in children diagnosed 2009–2012. Reports discrimination (C-index with bootstrap CIs), calibration slope, era-specific hazard ratios with factor × era interaction tests, and observed-minus-predicted 3-year recorded event-free survival by subgroup. Includes an independently written rebuild that reproduces the main results.
- **Acute myeloid leukemia (TARGET-AML).** The same audit, adapted to AML predictors and eras (development ≤2010, validation 2011–2017; APL trial AAML0631 excluded), as a second-cancer portability check. Includes a data-quality audit and an independently written rebuild that reproduces the main results.

## Key results

| | Neuroblastoma | AML |
|---|---|---|
| Patients / first events | 814 / 400 | 1,993 / 1,055 |
| C-index, development (apparent; optimism-corrected) → validation | 0.67; 0.66 → 0.57 | 0.64 (apparent) → 0.62 |
| Calibration slope in validation | 0.41 | 0.85 (bootstrap 95% CI 0.68–1.05) |
| Largest subgroup miscalibration (observed − predicted 3-year EFS) | Age ≥18 months +15.4 points; <18 months −14.5 points | *KMT2A*-rearranged −9.1 points; *FLT3*-ITD +7.8 points |

## Data

Download the open-access **Clinical** data (TSV) for projects **TARGET-NBL** and **TARGET-AML** from the GDC Data Portal (https://portal.gdc.cancer.gov). Unpack each into:

```
data/TARGET-NBL/   clinical.tsv, follow_up.tsv, ...
data/TARGET-AML/   clinical.tsv, follow_up.tsv, ...
```

The analyses in the submission used exports downloaded October 15–16, 2026. Raw data and patient-level cohort files are not included in this repository.

## Running

Python 3.11 with the packages in `requirements.txt`. Put the GDC downloads in `data/TARGET-NBL/` and `data/TARGET-AML/`, then run from this folder:

```
pip install -r requirements.txt

# Neuroblastoma
python nbl_build_cohort.py data/TARGET-NBL work/nbl_cohort.csv
python nbl_prelim.py          # temporal validation, COG risk groups, subgroup calibration
python nbl_era_effects.py     # era-specific hazard ratios and interaction tests
python nbl_comparator.py      # simplified model using published nomogram variables
python nbl_figure.py          # Figure 1 and subgroup table
python nbl_stress_tests.py    # optimism-corrected C-index; age x era interaction across era cut-points 2006-2010 and continuous calendar year

# AML
python aml_cohort.py data/TARGET-AML
python aml_analysis.py        # temporal validation and subgroup calibration
python aml_sens.py            # sensitivity analyses
python aml_audit_conflicts.py data/TARGET-AML           # data-quality audit
python aml_explore2.py data/TARGET-AML/follow_up.tsv    # counts of molecular test records

# Neuroblastoma independent rebuild (written separately, for the independent audit)
python nbl_independent_rebuild.py

# AML independent rebuild (written separately from a specification)
python aml_independent_build.py
python aml_independent_model.py
```

Aggregate outputs (`nbl_*.csv`, `nbl_fig1.png`, `aml_*.csv`) are written to this folder; the committed copies were produced by these scripts. Patient-level cohort files are written to `work/` and should not be committed.

## Notes and limitations

- Diagnosis era is a proxy for treatment era; no causal claims are made.
- The GDC export does not record test dates for molecular markers, so availability at diagnosis is assumed.
- "Recorded event-free survival" uses first events as recorded in the TARGET clinical export.
